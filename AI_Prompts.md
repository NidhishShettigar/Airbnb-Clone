# AI-Assisted Development Prompts

This file contains the main prompts used during the AI-assisted development of the project.

## 1. Initial Project Setup

Create a React + TypeScript project using Vite and set up the basic folder structure. Keep the project clean and component-based.

## 2. Header and Navigation

Create the desktop header and navigation for the listing page. Match the layout, spacing, typography, and search bar shown in the reference.

## 3. Listing Page Layout

Build the main listing page structure with the property title, location, rating, sharing options, image gallery, property details, and booking card.

## 4. Image Gallery

Create the five-image gallery layout shown in the reference. Make sure the images have the correct aspect ratios, spacing, rounded corners, and hover behavior.

## 5. Booking Card

Create the sticky booking card on the right side of the listing page with the price, date selection, guest selection, and reservation button.

## 6. Property Details

Add the property information sections such as sleeping arrangements, amenities, calendar, reviews, location, host information, and things to know.

## 7. Photo Tour

Add a Photo Tour view that opens when the user clicks "Show all photos". Organize the photos into groups and match the layout of the reference.

## 8. Lightbox

Add a full-screen lightbox for viewing individual photos. Include previous, next, and close controls.

## 9. Keyboard Navigation

Add keyboard support to the photo lightbox. Left and right arrow keys should change photos and Escape should close the lightbox.

## 10. Visual Refinement

Compare the current implementation with the provided reference screenshots and improve spacing, typography, image sizing, borders, alignment, and other visual details.

## 11. Accessibility

Review the interactive elements and improve accessibility by adding appropriate labels, keyboard focus states, semantic elements, and dialog behavior where required.

## 12. Small UI Fixes

Fix the alignment and spacing issues in the listing page without changing the existing functionality.

## 13. Responsive / Desktop Check

Check the page at the required desktop viewport and fix any overflow, spacing, or alignment problems.

## 14. Final Code Check

Review the project for unused imports, TypeScript errors, console errors, unfinished sections, and obvious UI issues. Fix only the problems found.
