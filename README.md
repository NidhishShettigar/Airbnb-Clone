# Airbnb Listing Take-Home

An original desktop-only React and TypeScript recreation of the supplied vacation-rental listing reference. The application uses static local data and has no backend.

## Run locally

Install Node.js 20+ and npm:

```sh
npm install
npm run dev
```

Open `http://localhost:5174`.

## Included experiences

- Complete desktop listing with sticky booking controls and section navigation
- Full-screen Photo Tour opened from any hero photo
- Lightbox with buttons, arrow keys, Escape handling, focus return, and scroll locking
- Static typed listing data and locally bundled photography
- Production marketplace architecture diagram in Mermaid, PNG, and PDF formats
- AI prompt history and focused review configurations

## Verification

```sh
tsgo --noEmit
npm run build
```
